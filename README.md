# Котобойня: Утиный вопрос

Небольшая законченная браузерная arena-survival игра: суровый чёрный кот автоматически отбивается от 20 волн агрессивных уток, собирает перья, повышает уровень и усиливается в магазине между раундами.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Управление

- **WASD / стрелки** — движение.
- **Esc** — пауза.
- **1 / 2 / 3** — выбор карточки при повышении уровня.
- На сенсорном экране — виртуальный джойстик слева внизу; также работает ведение пальцем по арене. Карточки улучшений, магазин и пауза управляются касанием.
- Оружие выбирает цели и атакует автоматически.

## Содержание

- 20 волн с ростом темпа, состава врагов и шанса элитных противников.
- 7 типов обычных противников и финальный босс «Мегаутка» с четырьмя атаками и второй фазой.
- 10 видов оружия с разными моделями атак; до 6 одновременно видимых и активных слотов, 4 уровня каждого оружия.
- Бита с отбрасыванием, тяжёлая лопата и независимые анимации всего арсенала вокруг кота.
- Level Up во время волны: пауза, выбор 1 из 3 бесплатных навыков, редкости и очередь накопленных повышений.
- 8 пассивных предметов, улучшения характеристик, обновление ассортимента магазина.
- Опыт, уровни, перья, автосбор ресурсов после волны, статистика забега.
- Процедурные звуковые эффекты через Web Audio; внешние аудиофайлы не нужны.
- Настройки и общая статистика сохраняются только локально: в `localStorage` текущего браузера или в отдельном профиле Electron-приложения.

## Windows 11 x64 / Electron

Готовая сборка не требует установки или интернета. Полностью распакуйте архив и запустите `Kotoboynya.exe`; остальные файлы и папки должны оставаться рядом с ним. **F11** переключает полноэкранный режим.

Повторная сборка из исходников:

```bash
npm install
npm run build:win
```

Результат создаётся в `release/Kotoboynya-win32-x64/`. Desktop-обёртка находится в `desktop/`: Node.js изолирован от игры, внешние переходы и открытие новых окон заблокированы, выход из меню завершает приложение.

## Структура

- `src/components/` — меню, HUD, магазин, настройки и результаты.
- `src/game/GameEngine.ts` — игровой цикл, волны, сущности и правила забега.
- `src/game/WeaponSystem.ts` — атаки оружия.
- `src/game/Renderer.ts` — векторная Canvas 2D-графика и адаптивная камера.
- `src/game/Input.ts` — клавиатурное и сенсорное управление.
- `src/game/SpatialGrid.ts` — пространственная сетка для локальных столкновений.
- `src/game/content/` — расширяемые конфигурации врагов, оружия, предметов и Level Up-навыков.
- `src/game/Audio.ts` — синтез звуковых эффектов.
- `src/game/storage.ts` — локальные настройки и статистика.

## Производительность

Используются фиксированный шаг симуляции, пулы противников, снарядов, перьев и частиц, пространственная сетка, отсечение объектов за пределами камеры и ограничение визуальных эффектов. Графика создаётся кодом; сторонние игровые ассеты не используются.
